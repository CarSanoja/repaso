# Design records

Two documents, both written in Spanish because that is the language the product
speaks to the families it serves.

| Document | What it is |
| --- | --- |
| [Flujo de una familia](flujo-de-una-familia.html) | How a family experiences the loop: what arrives in the chat, at what moment, how many questions, and how often the system asks for a decision. Every figure is read from the source or from a run against the deployed system. |
| [Sesiones, Bloom y memoria](sesiones-bloom-memoria.html) | A proposal for family-driven study sessions, and the second version of it. Three adversarial reviews measured the first version and cut the parts that cannot be measured, delivered or consented to. The document keeps what they cut and why. |

Open either file in a browser. They are self-contained: no build step, no network
except the font stylesheet, and they render in light and dark.

The second document is the more useful of the two for a reader deciding what to
build next, because it is the only record in this repository of a design being
argued down with numbers rather than approved.
