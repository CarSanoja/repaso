# Diagram archive

The existing SVG/PNG figures in this directory are historical design and simulator artifacts from August 2026. They are superseded for the hackathon candidate: some include earlier transport guarantees, scope, model statistics or memory plans. They must not be used as current evidence or inserted in the final video.

The maintained architecture is the Mermaid diagram in [README](../../README.md), with current behavior in [How it works](../product/how-it-works.md). Current results and their limits live in [the evidence register](../evidence/README.md). The candidate video is generated from current synthetic journey checkpoints, not these historical illustrations.
